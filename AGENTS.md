# Agent guide

## Project

This repo is self-contained. Keep changes focused and small.

## Conventions

- Do not commit secrets (API keys, tokens, .env). Only `.env.example` belongs in the repo.
- Use your GitHub noreply email for commits (or your configured git email) — do not hardcode another contributor's email.
- Keep this repo self-contained.
- Prefer small, routine hygiene commits over broad refactors.

## Branch / PR workflow

Open PRs against the default branch for review. Keep PRs small and focused.
